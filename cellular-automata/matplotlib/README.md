# Cellular Automata with Matplotlib

This imported project contains several cellular-automata experiments. The primary Python script builds and displays a one-dimensional elementary cellular automaton with Matplotlib, while `outputCA` contains a larger image-generating variant. The `testno` directory is an unfinished C++ graphics prototype using OpenGL-related libraries.

For the Python experiments, install Matplotlib, NumPy, and Pillow as required by the selected script, then run it from its own project directory. The C++ prototype retains its Visual Studio project but requires its external graphics dependencies to be restored and configured.
