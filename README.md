# Procedural and Algorithmic Labs

This repository consolidates several small educational projects and programming experiments created while learning the underlying concepts.

| [L-systems](l-systems/) | [June 2024](https://github.com/nivagion/procedural-and-algorithmic-labs/commit/cd4e2c87afbf47900572f86c8ba2b902f62025c9) | Python, NumPy, Matplotlib | Expands and plots an L-system-based fractal tree. |
| [Cellular Automata: Matplotlib](cellular-automata/matplotlib/) | [February 2024](https://github.com/nivagion/procedural-and-algorithmic-labs/commit/b2aafbd7dc62f381f2540167f6e696c5d0acb972) | Python, Matplotlib; C++ prototype | Contains one-dimensional cellular-automata experiments and an OpenGL prototype. |
