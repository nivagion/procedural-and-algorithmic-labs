# Procedural and Algorithmic Labs

This repository consolidates several small educational projects and programming experiments created while learning the underlying concepts.

| Project | Language / Technology | Description |
| --- | --- | --- |
| [Maze Generation](maze-generation/) | Python, NumPy, Matplotlib | Visualizes depth-first search, randomized Prim-style, and random-line maze generation. |
| [L-systems](l-systems/) | Python, NumPy, Matplotlib | Expands and plots an L-system-based fractal tree. |
| [Cellular Automata: Matplotlib](cellular-automata/matplotlib/) | Python, Matplotlib; C++ prototype | Contains one-dimensional cellular-automata experiments and an OpenGL prototype. |
| [Cellular Automata: 2D](cellular-automata/2d/) | Python, NumPy, Matplotlib | Animates a two-dimensional Conway's Game of Life grid. |
| [Binomial Distribution](binomial-distribution/) | Python | Calculates the probability of a selected number of successes. |
| [Compression](compression/) | Python | Demonstrates Lempel-Ziv-Welch compression and decompression. |
| [Error Correction](error-correction/) | Python | Generates and corrects Hamming(7,4) code words. |

Each directory preserves the imported project's Git history. See the project-level README files for available run or build notes.
